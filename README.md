## 📌 Sobre o projeto

O *EncontraAi* é uma aplicação web desenvolvida como parte do Projeto Integrador (PI) do curso de Desenvolvimento de Software Multiplataforma (DSM) da FATEC Franca.

A plataforma tem como objetivo ajudar motoristas a encontrar postos de combustíveis próximos, visualizar informações sobre os estabelecimentos e consultar preços disponibilizados pela Agência Nacional do Petróleo, Gás Natural e Biocombustíveis (ANP).

Por meio de uma interface intuitiva e de um mapa interativo, o usuário pode pesquisar postos por endereço ou localização atual, aplicar filtros e comparar os preços disponíveis.

## 🎯 Objetivos

- Facilitar a localização de postos de combustíveis.
- Permitir a comparação de preços.
- Ajudar motoristas a encontrar opções mais econômicas.
- Tornar a consulta de informações sobre combustíveis mais simples e acessível.

## 🚀 Funcionalidades

### 📍 Localização e pesquisa
- Pesquisa de postos por endereço.
- Utilização da localização atual do usuário via GPS do dispositivo.
- Sugestões automáticas de endereços.
- Definição do raio de pesquisa entre 1 km e 15 km.

### ⛽ Filtros de combustíveis
- Gasolina comum.
- Gasolina aditivada.
- Etanol.
- Diesel S10.
- Diesel S500.
- Filtro para visualização de postos com preços registrados na ANP.

### 🏷️ Filtros e ordenação
- Filtro por bandeira do posto.
- Ordenação por distância.
- Ordenação por preço do combustível selecionado.
- Identificação dos postos com e sem preços associados.

### 🗺️ Mapa interativo
- Visualização dos postos encontrados.
- Identificação da localização do usuário.
- Exibição dos preços no mapa quando um único combustível está selecionado.
- Visualização de informações dos estabelecimentos.
- Acesso à rota do posto pelo Google Maps.

### 📚 Conteúdo informativo
- Página institucional sobre o projeto.
- Página com dicas para economizar combustível.
- Interface adaptada para diferentes tamanhos de tela.

## 📊 Fontes de dados

O EncontraAi utiliza fontes externas e bases de dados em formato JSON:

- *ANP:* informações de preços de combustíveis.
- *OpenStreetMap:* dados geográficos e localização de estabelecimentos.
- *Nominatim:* serviço de pesquisa de endereços e conversão de endereços em coordenadas.
- *Leaflet:* biblioteca responsável pela apresentação dos mapas.

*Observação:* os preços apresentados dependem da disponibilidade e da data de coleta dos dados da ANP. É recomendável confirmar os valores diretamente com o estabelecimento antes do abastecimento.
